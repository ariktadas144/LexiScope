# Lexi language specification

## Keywords

`let`, `print`, `if`, `else`, `while`, `true`, `false`

## Literals

Numbers use decimal notation. Strings use double quotes. Boolean literals are `true` and `false`.

## Operators

Arithmetic: `+`, `-`, `*`, `/`
Comparison and assignment tokens are reserved for the next language phase.

## Statements

```lexi
let name = expression;
print expression;
```
