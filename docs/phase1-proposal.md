# LexiScope Phase 1 Proposal

Phase 1 delivers a browser-based compiler workbench for the Lexi teaching language. The user writes a program and observes tokenization, an abstract syntax tree, symbol table entries, three-address instructions, and interpreter output.

The pipeline is intentionally framework-agnostic so future phases can add richer grammar, optimization, diagnostics, and downloadable artifacts without coupling compiler logic to React.
